# Xross Stars 検証アプリ

Xross Stars の**一人回し / 対面検証 / デッキ調整**を目的とした、React + Vite + TypeScript 製のモバイル向け PWA アプリです。

このリポジトリは、ゲーム仕様の検証と UI・状態管理・ゲームロジックの土台を、ホーム画面追加やオフライン再表示に対応した形で提供することを目的としています。

---

## 概要

本プロジェクトでは、以下のような Xross Stars の基本進行を React 上で再現することを目指しています。

- 4 リーダー構成
- メインデッキ 50 枚
- タクティクスデッキ 5 枚
- ラウンド制（最大 3 ラウンド / 2 ラウンド先取）
- PP（Play Point）進行
- アタック / メモリア / タクティクス / 装備の基本処理
- 覚醒、山札再構築、手札調整などの主要ロジック

---

## 現在実装されている内容

### UI / 画面
- React + Vite + TypeScript の開発環境
- モバイル前提の MVP レイアウト
- 自分 / 相手の 4 リーダー表示
- 手札表示
- タクティクス山 / セット中タクティクス / 装備ゾーン表示
- ログ表示
- ラウンド / ターン / PP / 勝利数表示

### ゲームロジック
- カード定義を `src/data/cards.ts` に分離し、ゲームロジックとデッキ編集画面で共通参照
- 初期手札 4 枚
- ターン開始時 1 ドロー
- PP 管理
  - Round 1 = 3
  - Round 2 = 4
  - Round 3 = 5
- 手札からのカード使用時 PP 消費
- アタックカード処理
- メモリアカード処理
  - 次の 1 回の攻撃強化
  - ターン中攻撃強化
  - 回復
  - 直接ダメージ
- タクティクス処理
  - ラウンドごとに 1 枚セット
  - 同一ターン 1 枚まで使用
  - 先攻 1 ターン目は使用不可
- 装備タクティクスの装備ゾーン反映
- 相手リーダーをダウンさせたリーダーの覚醒
  - ATK +10
  - HP +30
- ラウンド勝利判定
- 2 ラウンド先取の試合進行
- ターン終了時の余り PP 分ドロー
- 手札上限 7 枚への調整
- 山札切れ時の再構築
  - トラッシュをシャッフルして山札化
  - 未選択タクティクス 1 枚をトラッシュ

## PWA / アプリ利用

- ホーム画面追加によるアプリ風起動に対応
- Service Worker による主要アセットのオフライン保存に対応
- Web Manifest / Apple Touch Icon を同梱
- JSON バックアップで端末間移行を補助

## セットアップ

### 1. インストール

```bash
npm install
```

### 2. 開発サーバー起動

```bash
npm run dev
```

### 3. 本番ビルド

```bash
npm run build
```

### 4. ビルド結果プレビュー

```bash
npm run preview
```

---

## 動作確認のポイント

開発サーバー起動後、以下を確認してください。

- 自分 / 相手リーダーが 4 体ずつ表示される
- 自分リーダー / 相手リーダーを選択できる
- 手札カードを押すと PP を消費して効果が反映される
- タクティクスをセット / 使用できる
- ターン終了で余り PP 分ドローされる
- 手札が 7 枚を超えた場合に調整が必要になる
- 相手リーダーをダウンさせると攻撃した自分リーダーが覚醒する
- ラウンド勝利後に次ラウンドへ進む
