# Xross Stars P1詳細作業表

- 対象: P1 16枚
- 方針: 共通処理を先に実装して、複数カードをまとめて解消する順番で並べ替え

## 作業グループ要約
- Phase 1 / A1: アタック前 任意ディスカード→打点上昇 共通化: 2枚
- Phase 2 / A2: アタック前 コスト0公開/捨て→ドロー+打点 共通化: 3枚
- Phase 3 / A3: アタック後 全員ディスカード: 1枚
- Phase 3 / A4: アタック後 メモリア総コスト参照ドロー: 2枚
- Phase 4 / A5: アタックカード自身が次アタック強化を付与: 1枚
- Phase 5 / M1: 2ドロー2ディスカード + 次アタック+30 共通化: 2枚
- Phase 5 / M4: 単体30回復 + 次アタック+30 共通化: 2枚
- Phase 5 / M5: 1ドロー1ディスカード: 1枚
- Phase 6 / M2: 山上1枚確認→任意トラッシュ + 次アタック+10: 1枚
- Phase 7 / M3: 同名カード参照のコスト踏み倒し + 次アタック+40: 1枚
